# Chicago AirBnB & Crime Visualization - Quick Start

## ✅ Setup Complete!

The visualization is now configured and ready to use.

## 🚀 How to Run

### Step 1: Make sure data is synced

In the notebook, run the data sync cell (or run manually):
```bash
./sync-data.sh
```

### Step 2: Start the server

```bash
npm run dev
```

This will:
- Start Parcel dev server on http://localhost:1234
- Automatically open your browser
- Enable hot reload for development

## 📊 What You'll See

The visualization displays:
- **Chicago Map**: 98 neighborhoods with boundaries
- **Green Dots**: 8,528 AirBnB listings (size = price)
- **Red Dots**: 3,783 homicide incidents
- **Timeline**: 73 monthly periods (2018-01 to 2024-01)

## 🔧 Troubleshooting

### Error: "Unexpected token '<'"

This means the data files aren't loading correctly. Fix:

1. **Sync the data**:
   ```bash
   ./sync-data.sh
   ```

2. **Clean and rebuild**:
   ```bash
   rm -rf .parcel-cache dist
   npm run dev
   ```

3. **Hard refresh browser**: 
   - Mac: Cmd + Shift + R
   - Windows/Linux: Ctrl + Shift + R

### Server won't start

Check if port 1234 is in use:
```bash
lsof -ti:1234 | xargs kill -9
npm run dev
```

### Data files missing

Run these notebook cells in order:
1. Data preparation cell
2. JSON export cell  
3. GeoJSON download cell
4. Data sync cell

## ✨ Technical Details

The visualization uses:
- **Parcel's `url:` imports** to bundle data files
- **D3.js v7** for geographic projections and visualization
- **d3.geoMercator()** for accurate Chicago mapping
- **d3.zoom()** for smooth pan and zoom

## 🌐 Alternative: Python Server

If you prefer not to use Parcel:

```bash
python3 -m http.server 8000
```

Then open: http://localhost:8000/src/chicago-map.html
